# Инструкция для новичка

## 1. Установи Android Studio

Скачай Android Studio с официального сайта Android Developers и установи как обычную программу.

## 2. Открой проект

1. Распакуй архив.
2. Открой Android Studio.
3. Нажми **Open**.
4. Выбери папку `DyadyaVityaAndroid`.

## 3. Дождись Gradle Sync

Android Studio сама скачает зависимости. Внизу может идти загрузка. Не закрывай окно.

## 4. Запуск на эмуляторе

1. Нажми **Device Manager**.
2. Создай телефон или планшет.
3. Нажми зелёную кнопку **Run**.

## 5. Запуск на телефоне

1. Включи режим разработчика на телефоне.
2. Включи USB debugging.
3. Подключи телефон кабелем.
4. В Android Studio выбери телефон сверху.
5. Нажми **Run**.

## 6. Если просит SDK

Нажми **Install missing SDK**. Android Studio сама поставит нужные компоненты.

## 7. Как добавить API-ключи

1. Найди файл `Config.example.properties`.
2. Скопируй его в файл `local.properties`.
3. Вставь ключи после знака `=`.

## 8. Как загрузить на GitHub

1. Создай репозиторий на GitHub.
2. В Android Studio открой меню **Git**.
3. Сделай commit.
4. Нажми push.

## 9. Где смотреть ошибки сборки

В GitHub открой вкладку **Actions**. Там будет список сборок. Нажми на красную сборку и открой лог.

## 10. Частые ошибки

- **Gradle Sync failed** — проверь интернет и версию Android Studio.
- **SDK not found** — установи SDK через подсказку Android Studio.
- **Maps key missing** — карта может не работать без ключа, но демо-приложение всё равно запускается.
- **Duplicate class** — удали старые зависимости, если сам добавлял новые библиотеки.
