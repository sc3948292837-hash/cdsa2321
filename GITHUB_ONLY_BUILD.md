# Сборка APK только через GitHub, без Android Studio и Java на компьютере

Этот архив сделан так, чтобы проект собирался в GitHub Actions.
На компьютере не нужны Android Studio, Java/JDK и Gradle.

## Самое важное

При загрузке на GitHub в корне репозитория должны быть видны файлы:

```text
app/
.github/
build.gradle.kts
settings.gradle.kts
gradlew
gradlew.bat
gradle.properties
README.md
```

Если на GitHub ты видишь только одну папку, например `DyadyaVityaAndroid/`, значит файлы загружены неправильно.
Нужно зайти внутрь распакованной папки и загрузить именно содержимое.

## Как загрузить правильно

1. Скачай архив.
2. Распакуй архив.
3. Открой распакованную папку.
4. Внутри выдели все файлы и папки: `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradlew` и остальные.
5. Загрузи их в новый репозиторий GitHub.

## Как запустить сборку

1. Открой репозиторий GitHub.
2. Перейди во вкладку `Actions`.
3. Выбери `Build Android APK in GitHub`.
4. Нажми `Run workflow`.
5. Дождись зелёной галочки.
6. Открой завершённый запуск.
7. Внизу скачай `DyadyaVitya-debug-apk`.
8. Внутри архива будет APK-файл.

## Что делает workflow

- сам ставит JDK 17;
- сам проверяет структуру проекта;
- сам делает файл `gradlew` исполняемым;
- сам скачивает Gradle 8.10.2;
- сам собирает debug APK;
- сам выкладывает APK в Artifacts.

## Если снова ошибка

Проверь, что `gradlew` лежит в корне репозитория. Не внутри подпапки, а именно рядом с `settings.gradle.kts`.
